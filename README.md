# Imperial Federation Modpack

## Members
1. Install Prism Launcher from https://prismlauncher.org.
2. Open Prism, click **Accounts → Manage Accounts → Add Microsoft**, and sign in.
3. Download https://imperialfederation.click/ImperialFederation-instance.zip and drag it into Prism (or **Add Instance → Import**).
4. Launch **Imperial Federation Modpack**; it updates itself every time you start it.
